PHẦN 1. PHÂN TÍCH VÀ SO SÁNH

1. Đường dẫn tuyệt đối và tương đối

Tuyệt đối:
- Ghi đầy đủ vị trí file.
- Ví dụ: C:\Users\Ban_Than\Desktop\Project\data\db.csv
- Đổi máy dễ bị lỗi vì phụ thuộc vào vị trí thư mục.

Tương đối:
- Dựa vào thư mục hiện tại.
- Ví dụ: data\db.csv
- Dễ chuyển project sang máy khác.

2. Tính thời gian tải

- Dung lượng: 2 GB
- Tốc độ mạng: 80 Mbps
- 1 Byte = 8 bit

80 Mbps : 8 = 10 MB/s

2 GB = 2 × 1024 = 2048 MB

Thời gian:
2048 : 10 = 204,8 giây

-> Khoảng 3 phút 25 giây.

=>Thực tế có thể lâu hơn do tốc độ mạng không ổn định.


PHẦN 2. HÀNH ĐỘNG

1. Relative Path

Nếu đang ở thư mục Project:
data\db.csv

Nếu file code nằm trong thư mục con:
..\data\db.csv

- . : thư mục hiện tại
- .. : thư mục cha

2. Kiểm tra đuôi file

File nhìn thấy:
tai-lieu-on-tap.pdf

Có thể file thật là:
tai-lieu-on-tap.pdf.exe

Cách kiểm tra:
File Explorer -> View -> Show -> File name extensions

Nếu thấy .pdf.exe thì đây là file .exe, không phải PDF.
Không nên mở vì có thể là mã độc.


=>KẾT QUẢ

- 80 Mbps = 10 MB/s
- 2 GB = 2048 MB
- Thời gian tải = 204,8 giây
- Relative Path = data\db.csv
- Bật File name extensions để kiểm tra đuôi file.
